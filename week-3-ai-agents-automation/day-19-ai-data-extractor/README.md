## What to build

Given messy text (receipts, forms, chat messages), extract structured JSON using the local LLM with a strict output schema. Add Zod validation on the NestJS side.

## Deep-dive topics

Research and understand these before or while building — this is the "why" behind the feature, not just the "how":

- Prompting for structured extraction from unstructured/messy text
- Defining a Zod schema and validating the model's JSON output against it
- Retry-with-error-feedback: re-prompting the model with the validation error when it fails

## Stack for this project

NestJS, Zod
