## What to build

Build a ReAct-style agent: Think → Act → Observe → Repeat. The agent calls tools until it has an answer. Implement in NestJS with a while loop and tool registry.

## Deep-dive topics

Research and understand these before or while building — this is the "why" behind the feature, not just the "how":

- The ReAct pattern explained step by step
- Implementing the loop safely: max iterations, timeout, and stopping conditions
- Logging each think/act/observe step for debuggability
