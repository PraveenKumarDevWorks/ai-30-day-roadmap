## What to build

Given a document, auto-generate 10 FAQs + answers using the local LLM. Store them. Build a FAQ widget for the frontend. One of the most useful features for SaaS products.

## Deep-dive topics

Research and understand these before or while building — this is the "why" behind the feature, not just the "how":

- Prompting for a numbered, structured FAQ list in valid JSON
- Caching generated FAQs so they're not regenerated on every page load
- Designing a simple accordion FAQ widget

## Stack for this project

Next.js, NestJS, Ollama
